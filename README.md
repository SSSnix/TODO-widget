#  Todo Widget

> Минималистичный, стильный виджет для рабочего стола с поддержкой прозрачности и гибкой кастомизацией. Всегда под рукой.

---

##  Возможности

### 🎨 Интерфейс и Дизайн
- **Glassmorphism UI:** Стильный полупрозрачный фон с размытием (`backdrop-filter`).
- **Кастомизация:** Настройки темы прямо внутри виджета:
    - Выбор типа фона: *Прозрачный* или *Сплошной*.
    - Ползунок прозрачности (0–100%).
    - Выбор цвета фона и готовые пресеты.
- **Always on Top:** Виджет всегда поверх остальных окон.

### ⚡ Функциональность
- **System Tray:** Сворачивание в трей, быстрый доступ через клик по иконке.
- **Drag & Drop:** Перетаскивание виджета за заголовок в любую точку экрана.
- **Локальная БД:** Надёжное хранение задач в JSON-файле (без тяжёлых зависимостей).
- **Управление задачами:** Добавление, отметка выполнения, удаление по двойному клику.

## 🛠 Технологический стек

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Core** | `Electron` | Обёртка для десктопного приложения |
| **Build** | `Vite` | Быстрая сборка и HMR (горячая перезагрузка) |
| **UI** | `HTML5 / CSS3` | CSS Variables, Flexbox, Glassmorphism |
| **Logic** | `Vanilla JS` | Чистый JS, IPC через Electron |
| **Storage** | `JSON` | Локальное хранение данных в `userData` |
